# Quantum33 Autonomous Phone Agent

Standalone Android host for the project-agnostic Python autonomous audit program.

The phone is the agent host. GitHub is infrastructure.

## Current state

Source architecture only. No APK has been built or executed yet.

## Planned capabilities

- explicit human command gateway
- Python agent core
- structured long-term memory
- provenance/evidence ledger
- web/knowledge provider interface
- GitHub repository control
- Simulation Matrix interface
- mechanical repair and adversarial verification
- Android UI

## Authority

Only commands explicitly entered by the human through the app are authoritative.

External repository content, web content, issues, pull requests, workflow logs, model output, and simulation output are evidence/input, never command authority.
