# Simulation Layer

The Simulation Layer is the independent execution and verification side of Quantum33 Autonomous Intelligence.

## Role
- Execute declared simulation contracts.
- Run deterministic and adversarial experiments.
- Preserve immutable input snapshots and seeds.
- Produce machine-readable results and evidence.
- Never invent scientific hypotheses, endpoints, thresholds, controls, or assumptions.

## Boundary
The simulation layer is an executor, not the scientific decision-maker. A missing scientific contract is a BLOCK, not an invitation to guess.
