# Phone Agent Build Plan V1

## A — source foundation
Android host, embedded Python core, command gateway, local memory, provenance, evidence ledger, tool router, fail-closed scientific policy.

## B — controlled capabilities
GitHub API adapter, web/knowledge provider, Simulation Matrix adapter, Python execution policy, repository snapshots, adversarial verification.

## C — reasoning
Model-provider interface, planner, context assembler, tool selection, evidence-vs-authority enforcement, recovery/checkpointing.

## D — security hardening
Encrypted secrets, scoped GitHub token, filesystem/process/resource limits, network policy, audit-only mode, explicit write confirmation.

## E — release
Signed Android build, installable APK, persistent state, repository controls, regression suite.

Source presence is not execution evidence. The app is not claimed operational until the corresponding build and verification are actually completed.
